Project 6 · Python · Ridge regression Walk-forward review

AI-Assisted Financial Forecasting

Can a Ridge regression model improve on a simple baseline for 20-trading-day price forecasts?

4.09%Return MAE (baseline)
4.10%Return MAE (Ridge)
52.9%Directional accuracy (Ridge)

Walk-forward model evaluation of Ridge regression against a simple baseline across multiple instruments and unseen yearly test periods. The Ridge model does not show consistent improvement — directional accuracy is lower (52.9% vs 57.7% baseline). This is an exploratory prototype, not investment advice.
